# Análise de Vendas com Power BI

Este projeto apresenta uma análise de vendas desenvolvida no Power BI, utilizando as tabelas **Vendas** e **Produtos** relacionadas pelo campo de produto. Os dados foram tratados no Power Query e utilizados na criação de medidas e indicadores no Power BI.

O dashboard analisa o perfil demográfico dos clientes, a performance por categoria, o ticket médio, a sazonalidade das vendas, a evolução do faturamento por estado e a relação entre faixa etária e categorias compradas. O relatório foi dividido em cinco páginas para facilitar a navegação e a interpretação dos resultados.

O objetivo é transformar os dados em informações úteis para apoiar decisões de segmentação de clientes, campanhas direcionadas, planejamento de estoque e definição do mix de produtos. **Ferramentas utilizadas:** Power BI, Power Query e DAX.
